# L10N Suite

Aplicación de escritorio para dirigir la actividad profesional de traducción de videojuegos, la investigación académica y un corpus de videojuegos. Sustituye a Notion, ClickUp y Google Sheets en un único espacio de trabajo. Los datos se guardan en tu equipo.

- **Qué es y hoja de ruta:** [docs/BRIEFING.md](docs/BRIEFING.md)
- **Instalar y usar:** [docs/MANUAL.md](docs/MANUAL.md)
- **Desarrollo:** [docs/DESARROLLO.md](docs/DESARROLLO.md)
